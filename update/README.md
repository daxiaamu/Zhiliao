# Update metadata

These files are generated by `.github/workflows/UpdateJson.yml` when a GitHub release is published.

- `update.json`: latest stable release
- `update-beta.json`: latest pre-release

Do not edit generated metadata by hand. GitHub Releases contain APK files only.
